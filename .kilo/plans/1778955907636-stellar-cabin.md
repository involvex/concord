# Plan: Hotkey Hints and Settings Screen

## Summary
Reimplement hotkey hint display and add a comprehensive settings screen with theme configuration and keyboard shortcuts customization.

## Current State Analysis

### Hotkey/Hint System
- No existing help/hint popup - the `?` key binding was previously removed
- The `Space` (leader) key currently shows basic shortcuts in a popup (`leader_popup_lines` in `src/tui/ui/popups/action_menu.rs`)
- Hotkeys are context-sensitive and defined in `src/tui/input/keyboard.rs`

### Settings/Options
- Current options popup (`OptionsPopup`) in `src/tui/ui/popups/options.rs` only handles display options
- Options state managed in `src/tui/state/options.rs`
- Config persisted via `src/config.rs` with `DisplayOptions` struct

## Implementation Plan

### 1. Hotkey Hint System

**File: `src/tui/input/keyboard.rs`**
- Add `?` key binding to trigger hotkey hint popup
- Handle German keyboard layout: `?` requires `Shift+=` on German keyboards (already handled by `is_shortcut_key` which accepts SHIFT modifier)

**File: `src/tui/ui/popups/help.rs`** (new)
- Create `render_hotkey_hints_popup` function
- Show categorized shortcuts:
  - Navigation: `j/k`, `J/K`, `g/G`, arrow keys
  - Message actions: `yrRdepv` (with space prefix)
  - Pane actions: `1/2/3/4`, `Alt+h/l`, `Alt+H/L`
  - Other: `` ` `` (debug), `i` (composer), etc.

**File: `src/tui/state/mod.rs`**
- Add `help_popup_open: bool` field to `DashboardState`
- Add `open_help_popup()` and `close_help_popup()` methods

**File: `src/tui/ui.rs`**
- Add render call for help popup

### 2. Enhanced Settings Screen

**File: `src/tui/ui/popups/settings.rs`** (new, replacing/refactoring options.rs)
- Create tabbed settings interface with:
  - Display tab (existing options + theme)

**File: `src/config.rs`**
- Add theme configuration struct:

**File: `src/tui/state/options.rs`**

### 3. Keyboard Shortcut Customization

**File: `src/tui/state/mod.rs`**
- Add `custom_keyboard_shortcuts: HashMap<String, String>` field

**Approach:**

## Key Design Decisions

1. **Help shortcut**: Use `?` key (Shift+= on German keyboards) - matches common TUI conventions
2. **Settings structure**: Tabbed interface within single popup for simplicity
3. **Theme system**: Start with accent color selection and selection style (bold vs underline)
4. **Shortcut customization**: Use string identifiers for actions, allow any key binding

## Questions for Clarification

1. Should the theme settings include full color customization or just preset themes (e.g., dark/light/dimmed)?
